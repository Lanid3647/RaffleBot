# Telegram Raffle Bot - Полная версия

Полнофункциональный Telegram-бот для проведения розыгрышей в каналах с автоматическим завершением, выбором победителей и админской панелью.

## 🎯 Реализованный функционал

### ✅ Базовая версия
- Регистрация и начало работы
- Добавление Telegram каналов
- Создание розыгрышей (12 шагов)
- Автоматическое завершение розыгрышей по времени
- Автоматический выбор победителей на основе билетов
- Публикация результатов в каналах
- Уведомления создателю и победителям
- Управление розыгрышами (просмотр, редактирование, удаление)
- CSV выгрузка участников
- Реферальная система
- Капча для защиты от ботов
- Буст (усиление шансов)

### ✅ Админская панель
- Просмотр статистики
- Управление пользователями
- Управление розыгрышами
- Детальная аналитика

## 🚀 Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка базы данных

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=your_bot_token_here
BOT_USERNAME=your_bot_username
DATABASE_URL=postgresql://user:password@localhost:5432/raffle_bot
WEBAPP_URL=https://your-webapp-url.com
```

### 3. Создание таблиц БД

```bash
python create_tables.py
```

### 4. Применение миграций

```bash
python migrations/add_new_fields.py
```

### 5. Запуск бота

```bash
python bot.py
```

## 🔧 Настройка администратора

Для назначения пользователя администратором выполните SQL запрос:

```sql
UPDATE bot_users SET is_admin = TRUE WHERE telegram_id = YOUR_TELEGRAM_ID;
```

## 📊 Основные возможности

### Создание розыгрыша
1. Нажмите "Создать розыгрыш 🎁"
2. Следуйте инструкциям (12 шагов)
3. Розыгрыш автоматически опубликуется в выбранных каналах

### Управление розыгрышами
- Просмотр списка розыгрышей
- Просмотр результатов
- Редактирование (текст, медиа, название)
- Удаление розыгрышей
- Скачивание CSV с участниками

### Автоматическое завершение
- Розыгрыши автоматически завершаются по истечении времени
- Победители выбираются случайным образом на основе билетов
- Результаты публикуются в каналах
- Уведомления отправляются создателю и победителям

### Админская панель
- Статистика пользователей и розыгрышей
- Просмотр списка пользователей
- Просмотр списка розыгрышей
- Детальная аналитика

## 🔐 Безопасность

- Валидация initData от Telegram
- Проверка прав бота в каналах
- Капча для защиты от ботов
- Проверка подписок на каналы

## 📝 Примечания

- Мини-приложение должно быть развернуто на HTTPS сервере
- Для работы планировщика бот должен работать постоянно
- Рекомендуется использовать процесс-менеджер (systemd, supervisor) для продакшена

## 🐛 Известные проблемы

- Интеграция с ВКонтакте отменена заказчиком
- Репост в Истории (Telegram Premium) не реализован

## 📞 Поддержка

При возникновении проблем проверьте:
1. Правильность настроек в `.env`
2. Подключение к базе данных
3. Логи бота в консоли
