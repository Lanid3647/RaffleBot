# 📋 Инструкция по тестированию бота для заказчика

## 🚀 Быстрый старт для тестирования (через ngrok)

### Вариант 1: Тестирование БЕЗ выкладки на сервер (рекомендуется для быстрого теста)

**Преимущества:**
- ✅ Можно протестировать сразу, не нужно настраивать сервер
- ✅ Быстро и просто
- ✅ Подходит для демонстрации заказчику

**Недостатки:**
- ⚠️ URL меняется при каждом перезапуске ngrok (бесплатный план)
- ⚠️ Нужно держать компьютер включенным
- ⚠️ Не подходит для постоянной работы

#### Шаги:

1. **Установите ngrok** (если еще не установлен):
   - Скачайте с https://ngrok.com/
   - Зарегистрируйтесь и получите токен
   - Настройте: `ngrok config add-authtoken ваш_токен`

2. **Запустите бота**:
   ```bash
   cd miniapp
   python run.py
   ```
   Дождитесь сообщения: `INFO: Uvicorn running on http://0.0.0.0:8000`

3. **В отдельном терминале запустите ngrok**:
   ```bash
   ngrok.exe http 8000
   ```
   (или `ngrok http 8000` на Linux/Mac)

4. **Скопируйте HTTPS URL** из ngrok (например: `https://abc123.ngrok-free.app`)

5. **Настройте переменную окружения**:
   - Откройте файл `.env` в корне проекта
   - Добавьте или измените строку:
     ```
     WEBAPP_URL=https://abc123.ngrok-free.app
     ```
   - **ВАЖНО:** URL должен быть HTTPS (не HTTP) и без слэша в конце!

6. **Перезапустите бота** (чтобы он подхватил новый URL)

7. **Настройте URL в BotFather** (если нужно):
   - Откройте @BotFather в Telegram
   - Отправьте `/mybots`
   - Выберите вашего бота
   - Выберите "Bot Settings" → "Menu Button"
   - Выберите "Configure menu button"
   - Отправьте URL: `https://abc123.ngrok-free.app`

8. **Готово!** Теперь заказчик может:
   - Открыть бота в Telegram
   - Нажать кнопку "🌐 Открыть мини-приложение"
   - Протестировать функционал

### Вариант 2: Выкладка на сервер (для постоянной работы)

**Преимущества:**
- ✅ Постоянный URL
- ✅ Работает 24/7
- ✅ Подходит для продакшена

**Недостатки:**
- ⚠️ Нужен сервер (VPS, облако)
- ⚠️ Требуется настройка домена и SSL
- ⚠️ Больше времени на настройку

#### Шаги:

1. **Арендуйте VPS/сервер** (например, на DigitalOcean, AWS, Hetzner)

2. **Настройте сервер:**
   - Установите Python 3.9+
   - Установите PostgreSQL
   - Настройте домен и SSL (Let's Encrypt)

3. **Загрузите код на сервер**

4. **Настройте переменные окружения** на сервере:
   ```
   BOT_TOKEN=ваш_токен
   WEBAPP_URL=https://ваш-домен.com
   DATABASE_URL=postgresql://...
   ```

5. **Запустите бота на сервере** (через systemd, supervisor или screen)

6. **Настройте URL в BotFather** (как в варианте 1)

---

## ⚠️ Важные замечания

### Для тестирования через ngrok:

1. **URL меняется** при каждом перезапуске ngrok (бесплатный план)
   - Решение: используйте ngrok с фиксированным доменом (платный план) или обновляйте WEBAPP_URL каждый раз

2. **Компьютер должен быть включен** пока идет тестирование

3. **Проверьте, что порт 8000 не занят** другим приложением

4. **Убедитесь, что бот запущен** перед запуском ngrok

### Для продакшена:

1. **Используйте HTTPS** - Telegram требует HTTPS для миниприложений

2. **Настройте домен** - лучше использовать собственный домен, чем ngrok

3. **Настройте мониторинг** - чтобы знать, если бот упал

4. **Сделайте резервные копии** базы данных

## 🔍 Проверка работоспособности

После настройки проверьте:

1. ✅ Бот отвечает на команду `/start`
2. ✅ В меню бота есть кнопка "🌐 Открыть мини-приложение"
3. ✅ При нажатии на кнопку открывается миниприложение
4. ✅ Миниприложение загружается и работает
5. ✅ Регистрация работает
6. ✅ Все функции миниприложения работают

---

## 📞 Если что-то не работает

1. **Проверьте логи бота** - там будут ошибки
2. **Проверьте логи ngrok** - убедитесь, что туннель активен
3. **Проверьте переменную WEBAPP_URL** - она должна быть HTTPS
4. **Проверьте, что веб-сервер запущен** на порту 8000
5. **Проверьте настройки в BotFather** - URL должен совпадать с WEBAPP_URL

---

## 💡 Рекомендация

**Для постоянной работы:** выложите на сервер (Вариант 2)
