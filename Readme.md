## 🎯 Описание проекта

Telegram Raffle Bot - это комплексное решение для проведения розыгрышей в Telegram каналах. Бот поддерживает автоматическое завершение розыгрышей, выбор победителей на основе билетов, публикацию результатов в каналах и многое другое.

## 🚀 Установка и настройка

### 1. Установка зависимостей

```bash
# Установка основных библиотек
python -m pip install sqlalchemy
python -m pip install psycopg2-binary
python -m pip install python-telegram-bot
python -m pip install fastapi
python -m pip install uvicorn
python -m pip install python-dotenv
python -m pip install python-multipart
python -m pip install jinja2

# Или установка из requirements.txt
pip install -r requirements.txt
```

### 2. Установка PostgreSQL

#### Windows:
1. Скачайте PostgreSQL с официального сайта: https://www.postgresql.org/download/windows/
2. Установите через установщик
3. Запомните пароль для пользователя postgres

#### macOS (через Homebrew):
```bash
# Установка
brew install postgresql

# Запуск
brew services start postgresql

# Или для конкретной версии
brew services start postgresql@14

# Проверка статуса
brew services list
```

#### Linux (Ubuntu/Debian):
```bash
sudo apt update
sudo apt install postgresql postgresql-contrib
sudo systemctl start postgresql
sudo systemctl enable postgresql
```

### 3. Настройка базы данных

#### Создание базы данных и пользователя:

```bash
# Подключение к PostgreSQL
psql -U postgres

# Создание базы данных
CREATE DATABASE raffle_bot;

# Создание пользователя
CREATE USER bot_user WITH PASSWORD '9349386375365';

# Выдача прав
GRANT ALL PRIVILEGES ON DATABASE raffle_bot TO bot_user;

# Выход
\q
```

#### Подключение к базе данных бота:
```bash
psql -U bot_user -d raffle_bot -W
# Введите пароль: 9349386375365
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
# Токен бота от @BotFather
BOT_TOKEN=your_bot_token_here

# Имя бота (без @)
BOT_USERNAME=your_bot_username

# URL базы данных PostgreSQL
DATABASE_URL=postgresql://bot_user:9349386375365@localhost:5432/raffle_bot

# URL мини-приложения (должен быть HTTPS)
WEBAPP_URL=https://your-webapp-url.com
```

**Важно:** 
- `BOT_TOKEN` можно получить у [@BotFather](https://t.me/BotFather)
- `WEBAPP_URL` должен быть HTTPS для работы мини-приложения
- Для локальной разработки используйте NGROK (см. раздел ниже)

### 5. Создание таблиц в базе данных

```bash
python create_tables.py
```

### 6. Применение миграций

**Важно:** Перед первым запуском необходимо применить миграции для добавления новых полей в базу данных.

```bash
# Удобный способ (рекомендуется)
python apply_migration.py

# Или напрямую
python migrations/add_new_fields.py
```

Миграция добавит следующие поля в таблицу `raffles`:
- `channel_messages` - для хранения ID постов в каналах
- `winners_selected` - флаг выбора победителей
- `completed_at` - время завершения розыгрыша

**Проверка таблиц:**
```bash
psql -U bot_user -d raffle_bot -W
\dt                    # Список всех таблиц
\d bot_users          # Структура таблицы bot_users
\d raffles            # Структура таблицы raffles
\d participants       # Структура таблицы participants
```

## 🎮 Запуск проекта

### Быстрый запуск (рекомендуется):

Для запуска бота используйте универсальный скрипт:

```bash
python start.py
```

Этот скрипт автоматически:
- Проверит наличие и корректность `.env` файла
- Проверит применение миграций базы данных
- Запустит Telegram бота (основной компонент - текстовый интерфейс)
- Опционально запустит веб-сервер мини-приложения (только если настроен WEBAPP_URL)

**Важно:** 
- Бот работает полностью через текстовый интерфейс (команды и кнопки)
- Мини-приложение используется только для участия в розыгрышах участниками
- Создание розыгрышей, управление каналами и все остальное - через текстовый интерфейс бота

**⚠️ Если при запуске появляется ошибка о недостающих полях в БД:**
```bash
# Примените миграции
python apply_migration.py

# Затем запустите снова
python start.py
```

### Запуск компонентов отдельно:

#### Запуск основного бота:

```bash
python bot.py
```

Бот автоматически:
- Подключится к базе данных
- Запустит планировщик для автоматического завершения розыгрышей
- Начнет обрабатывать команды и сообщения

#### Запуск мини-приложения (WebApp):

```bash
# Запуск веб-сервера на порту 8000
python miniapp/run.py
```

Мини-приложение будет доступно по адресу: `http://localhost:8000`

**Для тестирования через Telegram используйте NGROK** (см. раздел ниже)

## 🎯 Основные возможности

### Создание розыгрыша

1. Нажмите кнопку **"Создать розыгрыш 🎁"** в главном меню
2. Следуйте инструкциям (12 шагов):
   - Выбор типа определения победителей (Автоматический/Самостоятельный)
   - Количество победителей (1-10 для базовой версии)
   - Служебное название розыгрыша
   - Время начала и окончания
   - Текст и медиафайл (фото, видео, GIF)
   - Реферальный бонус (0-5 приглашенных)
   - Выбор каналов публикации
   - Выбор каналов для проверки подписки
   - Дополнительные опции (Буст, Капча)
   - Финальное подтверждение
3. Розыгрыш автоматически опубликуется в выбранных каналах

### Управление розыгрышами

- **"Мои розыгрыши 🗒"** - просмотр всех ваших розыгрышей
- Просмотр деталей розыгрыша
- Просмотр результатов и победителей
- Редактирование (текст, медиа, название)
- Удаление розыгрышей
- Скачивание CSV с участниками

### Автоматическое завершение

- Розыгрыши автоматически завершаются по истечении времени окончания
- Победители выбираются случайным образом на основе билетов участников
- Результаты автоматически публикуются в каналах
- Уведомления отправляются создателю и победителям

### Админская панель

Доступна только для администраторов:
- **"👑 Админ-панель"** - главное меню администратора
- Просмотр статистики (пользователи, розыгрыши, участия)
- Список пользователей
- Список розыгрышей
- Детальная аналитика

## 🌐 NGROK для тестирования

NGROK нужен для создания тестовой ссылки на веб-страницу, которую может увидеть Telegram извне локальной сети. Это необходимо для тестирования мини-приложения, так как оно по сути является сайтом.

### Настройка ngrok:

1. Установите ngrok с официального сайта: https://ngrok.com/
2. Зарегистрируйтесь и получите токен
3. Настройте токен: 
   ```bash
   ngrok config add-authtoken ваш_токен
   ```

**Токен для NGROK (если нужен):**
```
38XU77MKmZ9P4JN4xWktHFy1IBW_4n7guT7u75jVnVkdZFNgq
```

### Запуск тестового сервера:

1. **Сначала запустите веб-сервер:**
   ```bash
   python miniapp/run.py
   ```
   Сервер будет доступен на порту 8000

2. **Затем в отдельном терминале запустите ngrok:**
   ```bash
   ngrok.exe http 8000
   ```
   (На macOS/Linux: `ngrok http 8000`)

3. **Скопируйте HTTPS URL** из вывода ngrok (например: `https://abc123.ngrok.io`)

4. **Обновите `.env` файл:**
   ```env
   WEBAPP_URL=https://abc123.ngrok.io
   ```

5. **Перезапустите бота** для применения изменений

**ВАЖНО:** 
- Веб-сервер должен быть запущен ДО запуска ngrok!
- При каждом перезапуске ngrok URL меняется, нужно обновлять `.env`

### Исправление ошибок NGROK:

- **ERR_NGROK_9040** - включите VPN
- **ERR_NGROK_105** - неверный токен (проверьте настройку токена)
- **ERR_NGROK_8012** - сервер не запущен или неправильный порт
